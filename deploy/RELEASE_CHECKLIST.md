# Контрольный список выпуска

Выпуск принимается, только когда пройдены все пункты; результаты записываются
в таблицу ниже с ревизией. Старые отчёты не подтверждают новую версию без
сопоставления версий (`pipeline.version`, `pipeline.models`, SHA артефактов из
`ml/EVALUATION_PROTOCOL.md`).

## Пункты

1. Frontend: `cd frontend && npm run verify` и `npm run e2e`.
2. Backend: `docker compose --profile tests run --rm backend-tests` (Linux, chDB,
   `REQUIRE_CHDB=1`), `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`.
3. Живая интеграция: `docker compose up -d --build api frontend`,
   `cd frontend && E2E_BASE_URL=http://localhost:8080 npm run e2e:live`.
4. Миграции применяются сервисом `migrate` на копии рабочей БД; `release.sh`
   делает резервную копию перед миграцией. Миграции только добавляют таблицы и
   столбцы, поэтому прежняя версия API продолжает читать БД; поиски,
   сохранённые новой версией (payload v2), прежняя версия не открывает.
5. Release smoke (`deploy/smoke.sh`, Linux CI): загрузка CSV → обработка →
   закупка с поиском → поиск по `searchId` → профиль → выгрузка → изоляция
   сессии → отказ неуспешного релиза и откат `api` и frontend.
6. Версии: ревизия Git, `pipeline.version`, SHA модели и векторов, версия набора
   ИНН (`pipeline.noveltySet`), версия контракта (`contractVersion`).
7. Локальные веса энкодера подготовлены заранее, внешних нейросетевых API в
   рабочем сценарии нет (`OLLAMA_NO_CLOUD=true`, модель из локального кеша).
8. Вручную: URL интерфейса, поиск, CSV, повторное открытие закупки и поиска,
   источники карточек, профиль, выгрузка; демонстрационные кейсы из `docs/demo`.

## Известные ограничения

- История закупок, новизна и ML-канал на локальном стенде не загружены
  (`degraded`: `history`, `novelty`); полноценные кейсы с новыми поставщиками
  и ролями из реестра МСП проверяются только на сервере.
- p95 поиска во время обработки большой загрузки — 3,12 с (цель 3 с).
- Полный конвейер с каталогом (D2) и экспертная проверка новых поставщиков (D3)
  подготовлены, но не выполнены.
