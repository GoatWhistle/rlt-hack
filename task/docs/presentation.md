Основной текст, требования и критерии переданы по слайдам. Таблицы на слайдах 4–5 представлены скриншотами с обрезанным текстом и научной записью одного ИНН. Для тех же показанных строк полные значения восстановлены из соответствующих CSV в `../data/`; это отмеченное дополнение к видимому тексту презентации. ## Слайд 1. Разработка интеллектуального сервиса

Комитет по государственному заказу Санкт-Петербурга.
RLT — Университет Росэлторг.

**Разработка интеллектуального сервиса поиска релевантных поставщиков, производителей и дистрибьюторов**

Для АИС ГЗ и электронного магазина Санкт-Петербурга.

**Целевой сценарий:** по данным закупки сформировать ранжированный список потенциально релевантных контрагентов.

## Слайд 2. Что вам предстоит сделать

1. Проанализировать предоставленные организаторами данные.
2. Определить бизнес-смысл полей исходных дата-сетов.
3. Создать методологию подбора релевантных контрагентов.
4. Разработать механизм поиска поставщиков, производителей и дистрибьютеров в открытых источниках.
5. Сформировать механизм обогащения данных по контрагентам.
6. Обеспечить удобный и интуитивно понятный пользовательский веб-интерфейс.
7. Протестировать систему на реальных кейсах.
8. Предусмотреть возможность масштабирования системы.
9. Продемонстрировать работоспособность проекта.
10. Презентовать проект.
