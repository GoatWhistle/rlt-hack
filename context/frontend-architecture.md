# Решения по фронтенду

- Правила качества взяты из проекта assemblyai-hack: никаких комментариев, файлы до 250 строк, пакеты до 20 файлов, запрет пакетов `utils`/`common`/`lib`, токены вместо литералов, CSS-модуль рядом с компонентом, правила проверяются скриптами с тестами в обе стороны.
- Двуязычность устроена как в GoatWhistle: тексты в JSON по папке на язык, но без ленивой подгрузки (словари маленькие). Ключи `t()` типизированы через `CustomTypeOptions`, язык по умолчанию — русский.
- Стили — CSS Modules, не Tailwind: каждый компонент держит свой небольшой лист. Повторы блоков ловит проверка `css-duplicates`.
- Визуальная система и привязка к кейсу появятся позже, сейчас токены нейтральные (системные цвета).
- Отображение ошибок, анимации открытия и закрытия и 404 входят в базовую настройку.
- TypeScript 6.0: проверка комментариев использует JS API компилятора, которого нет в 7.x.
