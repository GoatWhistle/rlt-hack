# Окружение экспериментов

Пользователь выбрал аренду GPU за 22 ₽/час и разрешил два параллельных эксперимента: Qwen3-Embedding-0.6B и Qwen3-Embedding-4B.

## Машина данных

Исходная машина: `/root/rlt`, неизменённые README и архив CSV. Здесь хранить план, управление запусками, журнал, агрегированные метрики, логи и резервные копии результатов. Текущие ресурсы: 4 CPU, 7.7 GiB RAM, около 47 GB свободного диска. Python для ML — отдельное окружение 3.12; backend команды использует свою версию 3.14.

## GPU-машина

Проверка SSH выполнена 2026-10-01:

- NVIDIA GeForce RTX 5060 Ti, 16 311 MiB памяти по `nvidia-smi`.
- Driver 570.153.02, CUDA capability драйвера 12.8. Заявленный в аренде Max CUDA 13 не совпал с фактической версией; используется сборка PyTorch CUDA 12.8.
- Python 3.12.3.
- 48 CPU по `nproc`; `free` показывает 125 GiB RAM хоста и диск 300 GB. Реально доступная квота контейнера проверяется отдельно, цифры хоста не считаются гарантированной выделенной квотой.
- При первой проверке GPU-память не занята; наблюдаемая загрузка GPU 100 % при пустом списке процессов требует проверки фактической производительности прогоном.

На GPU-машине можно выполнять и CPU-часть экспериментов: построение индекса и расчёт метрик. На машине данных остаются управление и резервные копии. Производные данные передаются напрямую между серверами, локально не скачиваются.

## Два параллельных сравнения

Готовые модели, без дообучения: одинаковая история до 2024-12-01, одинаковая валидация первого полугодия 2025, seed 42, 256 токенов, общий BM25, RRF и top-100 поставщиков. Размеры inference batch могут различаться по памяти, остальные параметры фиксированы.

Приблизительный размер только весов bf16: 0.6B — около 1.2 GB, 4B — около 8 GB. Это расчёт, а не измеренный расход VRAM: сверху нужны CUDA context, активации и буферы. Индекс остаётся в RAM. Для 4B стартовый batch 1–2, для 0.6B — 4–8. Пики памяти фиксируются в отчётах.

Первый параллельный прогон подтвердил размещение двух процессов: суммарно занято 9,336 MiB из 16,311 MiB GPU, загрузка 63 %, OOM нет. На раннем участке каждый процесс закодировал несколько сотен карточек за ~20 секунд; это не полный замер скорости. В образе Torch предупреждает, что собран против NumPy 1 при установленном NumPy 2; GPU bf16 и encoder forward работают, а перенос тензоров реализован без NumPy C-API моста и проверен отдельно.

Полное дообучение 4B в этой памяти не планируется. LoRA для 0.6B — следующий эксперимент, только после оценки готовых моделей. Время и итоговая стоимость до измерений не обещаются.

Цена из сообщения пользователя: 10 часов — 220 ₽, 24 часа — 528 ₽, без учёта иных сборов площадки. Машина не выключается без указания пользователя.

Источники совместимости: [PyTorch 2.7+ / CUDA 12.8 и Blackwell](https://pytorch.org/blog/pytorch-2-7/), [NVIDIA RTX 5060 Ti](https://www.nvidia.com/en-us/geforce/graphics-cards/50-series/rtx-5060-family/), [Qwen3 Embedding](https://huggingface.co/Qwen/Qwen3-Embedding-4B).
