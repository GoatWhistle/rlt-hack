# Документация Lotive

> Lotive по данным закупки строит ранжированный список поставщиков и для каждой компании
> показывает основания: прошлые закупки в категории, их даты и ссылки, регион из реестра МСП,
> предложения из открытых каталогов. Здесь собрано, как это устроено, как запускается и как
> измерено качество.

Начните с [README проекта](../README.md): там идея, схема и короткий путь по живому сервису.
