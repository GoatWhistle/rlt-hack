# Структура презентации

10 слайдов, защита 5 минут. Сквозной пример: одна закупка из `Тестовые данные_1140`. До выбора и проверки лота в тексте стоит `[ЛОТ]`; примеры ниже отмечены «проверить», если не подтверждены предметно. Метки `[НУЖНО …]` — блокеры: пока они не закрыты, утверждение нельзя ставить на слайд.

Правила для всех слайдов: не писать «высокая точность», «масштабируется», «уникальный». Новизна всегда «относительно исходного архива организаторов». Score без расшифровки не показывать. Исторические победы не выдавать за гарантию будущей поставки.
