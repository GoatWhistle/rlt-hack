# Единые рекомендации CSV и формы

## Зафиксированное состояние — 02.10.2026

Production: 79f3760; main: 7dd1d8c. CSV использует исторический Qwen4B/CatBoost,
форма — каталоговые каналы и фиксированную формулу. Общего ранжирования пока нет.
Таблицы procurement_lots, procurement_items, lot_participations требуют полного
импорта; supplier_procurement_evidence содержит только примеры из карточек.
Импорт регионов МСП продолжается под deploy.lock; checkpoint парсера и данные
не удаляются. Текущий импорт нельзя прерывать ради установки кода.

## Срочный дефект качества

Живой запрос «вода» воспроизведён: КАУРИ/кроссовки, Автокомпонент/запчасти,
Агрофармика/Цитогумат получили recommended по одному каналу lexical.
Префиксный поиск по описанию ошибочно использовался как подтверждение позиции.
Наличие предложения и подтверждённого продавца не доказывает соответствие запросу.

- [x] Отделить широкий отбор от подтверждения: полный стем названия вместо
  совпадения короткого префикса в описании; частичное совпадение — предположение.
- [x] Не повышать достоверность при слиянии двух слабых каналов.
- [x] Не считать предположения подтверждённым покрытием/наличием цены позиции.
- [x] Регрессионные проверки воды, кроссовок, водолазок, многословных запросов.
- [ ] Штатный релиз и повторная проверка сайта. Это техническая проверка,
  не оценка качества модели. Строгое подтверждение одинаковых нормализованных
  названий временно снижает полноту подтверждений; семантические кандидаты остаются.

## Основной объём

- [ ] Общий нормализованный контракт: текст, позиции, ОКПД2, заказчик, НМЦК,
  регион, лимит; CSV и форма вызывают один сервис.
- [ ] Объединённый пул истории, текста и актуальных предложений; склейка по
  подтверждённому ИНН; сохранение компаний без истории; только Qwen4B/2560.
- [ ] Единый CatBoost; проверка признаков и пропусков; серверное переобучение
  при изменении схемы, артефакт со срезом данных и версией.
- [ ] Полный серверный импорт истории с датами, источниками и проверкой связей;
  исторические закупки не превращаются в предложения.
- [ ] Единый ответ и компоненты интерфейса; факты отдельно от вкладов модели;
  регион МСП — мягкий бонус только при явном выборе; балл не вероятность.
- [ ] Проверки идентичности CSV/формы, регионов, новых компаний, нескольких
  позиций, неполных реквизитов, отказов каналов, ссылок, сохранения и задержек.
- [ ] Отдельная временная оценка качества без будущих данных; журнал экспериментов.
- [ ] Commit/push/CD, активный SHA, здоровье, checkpoint парсера, очередь
  батчевой векторизации и итоговые объёмы ClickHouse.

Датасеты и веса остаются на серверах. Чужие коммиты сохраняются; зелёный CI
с пропущенным deploy не считается установленной версией.

Локальная по характеру серверная проверка на искусственных данных: 93 теста,
13.21 с; дополнительно 131 сервисный/адаптерный тест, 11 архитектурных пропусков
из-за неполного корневого дерева тестового каталога. Mypy и Ruff прошли.
Полный набор запускается CI. Импорт МСП завершён: 6 767 447 строк в проходе.
