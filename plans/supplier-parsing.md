## Предыдущие работы и результаты

асинхронный: сервис `SupplierFetcher` запускает парсеры всех источников
конкурентно, те же сервисы будет вызывать будущее API на FastAPI.

Проверено 1 октября 2026 года на chDB 4.1.2, движок ClickHouse 26.9.2.1:
применение миграций и его повторный запуск, запись компаний, предложений и
наблюдений, сохранение времени первой встречи, неизменность хеша при изменении
только цены, снятие с продажи после полного обхода, отсутствие снятия при
неизменившемся фиде и при пустом результате, повтор задания с тем же ключом,
курсор обхода, импорт компаний из CSV, обход всех источников одним запросом,
разбор карточки товара с разметкой schema.org, лимиты обхода, конкурентный
запуск источников, ограничение числа одновременных обходов и изоляция сбоя
одного источника. Для каталогов проверены отбор карточек из sitemap, разбор
`Organization`, `ItemList` и `knowsAbout`, два варианта разметки реквизитов
optkatalog.ru, пропуск карточки сервиса без компании, устойчивость ID и хешей
при повторном обходе и провал обхода при sitemap без карточек.

Прогон через Docker Compose 1 октября 2026 года против ClickHouse 26.9.7, лимит
500 карточек на источник: все восемь адаптеров завершились успешно — YML-фиды
globalclimat.com (50 предложений) и sibrtex.ru (1973), сайты kdom.ru (500),
ateks-group.ru (492) и ninel-tex.ru (95), каталоги optkatalog.ru (499 компаний,
619 позиций), aboutpartner.ru (424 и 1293), texzakaz.ru (500 и 4088). В
хранилище 1425 компаний, из них 1002 с ИНН, 1240 с регионом, 897 с сайтом.
Короткий прогон с лимитом 40 подтвердил снятие с продажи исчезнувших предложений.

Не проверено и не сделано:

- Публичного API у источников нет: `/api/` закрыт в `robots.txt` у texzakaz.ru и
  aboutpartner.ru, у optkatalog.ru закрыты поиск, сортировка и постраничная
  навигация. Обход идёт по sitemap и разметке страниц.
- Соблюдение `robots.txt` в коде не проверяется: адреса разделов и перечней
  сверены вручную, автоматической проверки правил нет.
- `tests/clickhouse/schema_smoke.py` не запускается: он читает отсутствующий
  `context/clickhouse-schema.md`. К адаптерам это не относится.
- Карточки компаний у aboutpartner.ru узнаются по началу адреса `pc-producer-`:
  в том же разделе лежат карточки сервисов, и в sitemap они идут первыми.
- Карточки каталогов отдают номенклатуру без цен: цены есть только у YML-фидов и
  разметки `Offer` на сайтах поставщиков.
- ИНН публикуют не все карточки: на выборке 60 карточек он найден у 60 из 60 на
  texzakaz.ru, 57 из 84 на aboutpartner.ru и 31 из 60 на optkatalog.ru.
- Драйвер `clickhouse-connect` против реального сервера не проверялся; SQL
  репозиториев проверен на встроенном движке chDB.
- Запросы одного соединения с ClickHouse сериализованы блокировкой: драйвер
  синхронный, поэтому конкурентность даёт сеть и разбор, а не запись.
- Нет парсера PDF-прайсов и страниц, где каталог появляется после JavaScript.
- Нет обогащения компаний по реестру: названия, ОКВЭД и контакты не заполняются,
  `identity_status` остаётся `unverified`.
- Участие в лотах и ТРУ из исходных CSV не импортируются: это отдельная задача.
- Нормализация предложений, эмбеддинги, ранжирование и API не реализованы.
- Порядок версий между процессами опирается на часы узлов; внутри одного
  процесса источники делят общий счётчик версий.
