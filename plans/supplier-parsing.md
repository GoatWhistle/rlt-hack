# Джоба сбора поставщиков и ассортимента

Сбор компаний и их товаров из внешних источников в ClickHouse. Код полностью
асинхронный: сервис `SupplierFetcher` запускает парсеры всех источников
конкурентно, те же сервисы будет вызывать будущее API на FastAPI.

- [x] Разбить DDL на миграции и применять их командой с учётом контрольных сумм.
- [x] Добавить миграцию для позиций инкрементального обхода и параметров источника.
- [x] Описать единый интерфейс парсера и модели задания, свидетельства и пачки.
- [x] Реализовать адаптеры: YML-фид, сайт по sitemap и schema.org, каталог компаний, исходный CSV.
- [x] Вынести интерфейс репозитория в слой сервиса и реализовать его для ClickHouse.
- [x] Назначать устойчивые UUID, версии строк и хеш содержимого предложения.
- [x] Снимать с продажи только ненайденные предложения полного успешного обхода.
- [x] Держать всю реализацию парсинга в `adapter/parser`: по модулю на источник,
      загрузчик документов, реквизиты, идентификаторы и сборка готовых моделей.
- [x] Оставить в `models` только бизнес-модели; DTO парсинга и контроллера
      объявлять по месту использования.
- [x] Перевести код на asyncio: конкурентный обход источников вместо пула
      процессов, блокирующие операции — в пуле потоков.
- [x] Добавить команду джобы, Dockerfile и сервисы в корневой docker-compose.
- [x] Проверить миграции, сбор, парсеры и конкурентность без сервера и сети.

Проверено 1 октября 2026 года на chDB 4.1.2, движок ClickHouse 26.9.2.1:
применение миграций и его повторный запуск, запись компаний, предложений и
наблюдений, сохранение времени первой встречи, неизменность хеша при изменении
только цены, снятие с продажи после полного обхода, отсутствие снятия при
неизменившемся фиде и при пустом результате, повтор задания с тем же ключом,
курсор обхода, импорт компаний из CSV, обход всех источников одним запросом,
разбор каталога и карточки товара с разметкой schema.org, лимиты обхода,
пропуск закрытых robots.txt адресов, конкурентный запуск источников,
ограничение числа одновременных обходов и изоляция сбоя одного источника.

Не проверено и не сделано:

- Образ и docker-compose не запускались: демон Docker в среде недоступен.
- Драйвер `clickhouse-connect` против реального сервера не проверялся; SQL
  репозиториев проверен на встроенном движке chDB.
- Запросы одного соединения с ClickHouse сериализованы блокировкой: драйвер
  синхронный, поэтому конкурентность даёт сеть и разбор, а не запись.
- Селекторы каталогов взяты из обзора источников и не сверены с живыми
  страницами: источники каталогов заведены выключенными.
- Нет парсера PDF-прайсов и страниц, где каталог появляется после JavaScript.
- Нет обогащения компаний по реестру: названия, ОКВЭД и контакты не заполняются,
  `identity_status` остаётся `unverified`.
- Участие в лотах и ТРУ из исходных CSV не импортируются: это отдельная задача.
- Нормализация предложений, эмбеддинги, ранжирование и API не реализованы.
- Порядок версий между процессами опирается на часы узлов; внутри одного
  процесса источники делят общий счётчик версий.
