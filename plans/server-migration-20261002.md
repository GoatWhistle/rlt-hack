Владелец отдельно разрешил временные ключи переноса. Доступ ограничен
forced-command rsync, каталогами проекта, IP и сроком действия. Production
копируется только на чтение; GPU отправляет данные в изолированный каталог
под непривилегированным временным пользователем. После переноса ключи удаляются. В Git только код и отчёты.
Посторонние сервисы старого сервера не переносятся и не останавливаются.
