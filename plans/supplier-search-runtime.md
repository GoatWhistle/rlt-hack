Индекс содержит исторические профили, а не актуальный ассортимент. Результат
поиска не является вероятностью победы. CatBoost из RANK-002 не применяется:
он ухудшал порядок retrieval-кандидатов. Качество текущего подключения оценивается
отдельно от прежнего validation-бенчмарка; smoke-проверки его не заменяют.

Рабочая БД содержит только Qwen 4B: 65 473 вектора по 2 560 компонент,
30 617 ИНН. Таблицы `supplier_profile_embeddings` и `supplier_profile_indexes`.
Повторный импорт не размножает строки, целостность файлов проверяется SHA-256.
0.6B удалён из рабочей БД по указанию владельца. Исходные эксперименты сохранены.

Проверено: frontend verify — 169 тестов, покрытие веток 90.85%; 20 e2e;
backend smoke-проверки, включая импорт/повторный импорт/поиск в chDB и изоляцию
CSV-загрузок между сессиями. В runtime frontend отсутствует demo-gateway.
