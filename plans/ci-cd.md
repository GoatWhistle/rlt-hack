Локально пройдены frontend verify (176 тестов, покрытие от 93%), все 20
браузерных сценариев с повтором исправленных случаев, четыре backend smoke-test,
18 ML-тестов (один GPU-модуль пропущен), Ruff, ShellCheck, actionlint и сборки
двух Docker-образов. Исправлены тестовые зависимости от отсутствующего документа
с SQL, английского названия в русском CSV и настольной навигации на мобильном.

[GitHub Actions: успешный запуск 36905677621](https://github.com/GoatWhistle/rlt-hack/actions/runs/36905677621)
проверил ревизию `6eba167a15f22ab98555ccaae2eec53402abae82`. Прошли 176 тестов
frontend, все 20 браузерных сценариев, четыре backend smoke-test, 18 ML-тестов
(один GPU-модуль пропущен), линтеры и сборка контейнеров. На временной БД
проверены миграции с повторным применением, резервная копия и восстановление
таблицы с контрольной строкой. Заведомо неисправный frontend был отклонён,
предыдущий выпуск восстановился автоматически, исходная строка БД сохранилась.
Первый контейнерный прогон выявил недоступный для ClickHouse XML-конфиг;
исправлены права только у этого несекретного файла. Стадия production-деплоя
пропущена по условию workflow.

После этого запуска подтянуты новые коммиты `main` с адаптерами ProductCenter,
ГИСП и портала поставщиков Москвы. Пять дополнительных проверок этих адаптеров
прошли локально вместе с Ruff и добавлены в CI. Production-конфигурация
сохраняет добавленный в основном Compose том кеша ProductCenter; новые
провайдеры выключены по умолчанию. Повторный CI объединённой версии ожидается.

Деплой включается переменной `DEPLOY_ENABLED=true` после настройки сервера
и секретов. Установка постоянного пользователя с правами Docker ожидает
подтверждения владельца. Пользователь ещё не создан, секреты production
не установлены, приложение на сервере не запущено.

Проект разворачивается отдельно от существующих приложений: Compose-проект
`rlt-hack`, каталог `/opt/rlt-hack`, публичный порт 8081. Порты 80/443 уже заняты
Caddy. Данные и ML-запуски в `/root/rlt` сохраняются. HTTP API пока отсутствует,
фронтенд работает с демонстрационными данными. Обучение и обход внешних каталогов
не входят в автоматическое развёртывание.
