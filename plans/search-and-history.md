# Единый поиск и вкладка «История»

Статус: план, ждёт подтверждения. Реализуется только фронтенд. Разбор PDF, DOCX и XLSX на бэкенде не входит в этот план: интерфейс принимает эти форматы, но отправляет на обработку только поддерживаемые сейчас. Бэкенд идёт отдельной задачей.

## Зачем

Сейчас у пользователя два входа: «Поиск» для текста и «Загрузки» для файла. Плюс отдельная вкладка «Закупки». Алгоритм подбора у них сводится в один (`plans/unified-recommendations.md`), поэтому и интерфейс должен быть одним.

Пользователь — контрактный управляющий. У него на руках либо описание своими словами, либо выгрузка извещений, либо ТЗ файлом. Он не должен выбирать, «куда идти». Он приходит на одну страницу и даёт то, что есть.

Признак успеха: новый пользователь без подсказок за первую минуту понимает две вещи.
- В одно поле можно и написать, и бросить файл.
- Всё сделанное лежит в «Истории».

## Навигация

- Шапка: **«Поиск» и «История»**. «Загрузки» и «Закупки» уходят из шапки.
- Старые адреса продолжают открываться, ссылки и закладки не ломаются:
  - `/uploads` перенаправляет на `/history?tab=files`;
  - `/lots` перенаправляет на `/history?tab=files`;
  - `/uploads/:id` и `/uploads/:id/lots/:lotId` остаются экранами результата загрузки и закупки.
- В «Истории» выбранная колонка или вкладка и фильтр хранятся в адресе: `/history?tab=queries|files&q=…`.

## Страница «Поиск» (`/search`)

### Раскладка

- Заголовок и короткое пояснение остаются сверху.
- Ниже одна широкая панель ввода: большое текстовое поле на всю ширину колонки.
- Справа от поля, вертикальным столбиком на десктопе, две кнопки:
  - «Прикрепить файл»: вторичная, с иконкой скрепки;
  - «Найти»: основная.
- Под полем, в той же панели, таблетка региона (уже сделана) и строка форматов: «CSV, XLSX, PDF, DOCX — до 10 МБ».
- Панель «Недавние поиски» с главной уходит. Её место занимает «История». На главной остаётся компактная полоса: «Последние: …» — три последних запроса или файла ссылками и ссылка «Вся история →».

### Перетаскивание файла

- Вся страница становится зоной приёма. Пока файл тянут над окном, панель ввода подсвечивается рамкой цвета акцента (без анимации размеров) и меняет текст на «Отпустите файл — подберём поставщиков по его содержимому».
- Перетаскивание не единственный способ: кнопка «Прикрепить файл» открывает системный выбор файла. Это требование WCAG 2.2 про альтернативу перетаскиванию.

### Прикреплённый файл

- Файл появляется в панели как чип: иконка типа, имя (обрезается посередине, расширение видно всегда), размер, кнопка «Убрать».
- Текстовое поле при этом не исчезает и становится комментарием к файлу: «Уточнение к файлу (необязательно)». Это задел под единый алгоритм.
- Пока бэкенд понимает только CSV, кнопка «Найти» показывает его проверку: «18 закупок в файле», как сейчас в диалоге загрузки. Сводка и предпросмотр показываются раскрытием под панелью, а не модальным окном.
- Для PDF, DOCX и XLSX файл принимается и показывается чипом. Строка под ним честно сообщает: «Этот формат скоро будет разбираться автоматически — пока опишите закупку текстом или загрузите CSV». Кнопка «Найти» при этом активна, только если есть текст.

### Отправка

- Текст: переход на результат поиска, как сейчас.
- Файл с одной закупкой: сразу на экран этой закупки.
- Файл с несколькими закупками: на экран загрузки со списком закупок и ходом обработки. Это текущий `/uploads/:id`.

## Страница «История» (`/history`)

### Раскладка

- Десктоп (от 64rem): две колонки равной важности.
  - Слева «Запросы»: текстовые поиски.
  - Справа «Файлы»: загрузки.
  - У каждой колонки свой заголовок со счётчиком, своя внутренняя прокрутка (как сейчас в недавних поисках) и своя кнопка «Показать ещё».
- Планшет и телефон: одна колонка и переключатель-сегмент «Запросы | Файлы» сверху (уже есть `SegmentedControl`). Выбор хранится в адресе.
- Сверху общая строка поиска по истории: фильтр по тексту запроса или имени файла.
- Группы по давности в обеих колонках: «Сегодня», «Вчера», «3 дня назад», «На прошлой неделе», «В прошлом месяце» (уже сделано для запросов).

### Строка запроса

Уже есть, переносится как есть:
- текст запроса в две строки;
- чипы: «**2** позиции», «**20** кандидатов», «**3** рекомендовано»;
- время и шеврон.

### Строка файла

- Иконка типа файла: CSV, XLSX, PDF, DOCX — разные значки, у каждого есть текстовая подпись, не только цвет.
- Имя файла.
- Чипы: «**18** закупок», «**12** готово», «**3** требуют внимания» (янтарь, только если есть).
- Время.
- Пока загрузка обрабатывается, вместо чипов показывается тонкая полоса хода и «Обработано 7 из 18», без смены высоты строки.
- Клик открывает `/uploads/:id`.

### Пустые состояния

Объясняют и ведут дальше:
- Запросов нет: «Здесь появятся ваши запросы» и кнопка «Новый поиск».
- Файлов нет: «Загрузите выгрузку извещений или ТЗ — результаты сохранятся здесь» и кнопка «Загрузить файл», которая ведёт на `/search` и сразу открывает выбор файла.
- По фильтру ничего не найдено: «Ничего не нашлось по „…“» и кнопка «Сбросить фильтр».

## Состояния, которые нужно нарисовать

| Где | Состояние | Что видит пользователь |
|---|---|---|
| Поиск | Пусто | Поле с примером в подсказке, кнопки активны, форматы под полем |
| Поиск | Тянут файл | Подсветка панели, текст «Отпустите файл…» |
| Поиск | Файл CSV принят | Чип файла, сводка проверки, «Найти» активна |
| Поиск | Файл PDF, DOCX или XLSX | Чип файла и честная строка про скорую поддержку |
| Поиск | Неверный файл | Ошибка рядом с чипом: «Файл повреждён» или «больше 10 МБ» или «формат не поддерживается»; кнопка «Выбрать другой» |
| Поиск | Отправка | Кнопка с индикатором и стадии, как сейчас; поле и чип не прыгают |
| Поиск | Ошибка сервера | Текст по коду ошибки и «Повторить», введённое сохраняется |
| История | Загрузка | Скелет строк по раскладке, в каждой колонке свой |
| История | Ошибка | Ошибка внутри колонки и «Повторить»; вторая колонка работает |
| История | Обработка файла | Полоса хода в строке, без скачков |
| История | Длинные списки | Внутренняя прокрутка, «Показать ещё», закреплённые заголовки групп |

## Движение

- Появление чипа файла: fade и сдвиг на 4 px, 180 мс, ease-out. Удаление быстрее, 130 мс.
- Подсветка при перетаскивании: только цвет рамки и фона, 130 мс.
- Раскрытие сводки CSV под полем: свёртка через существующий `Fold` или `clip-path`, без анимации высоты.
- При reduced motion: только смена цвета, без сдвигов.

## Что переиспользуем

- `features/search-box`: поле, таблетка региона, стадии, ошибки.
- `pages/uploads`: `dropzone`, `check-summary`, `preview-table`, `processing-view` и проверка `entities/notice/check`. Вынести их из страницы в `features/file-intake`.
- `pages/search/recent-list`: группы по давности, чипы, история страницами, внутренняя прокрутка. Вынести в `features/history-list` с двумя источниками: запросы и загрузки.
- `shared/ui`: `MetaChips`, `SegmentedControl`, `EmptyState`, `Skeleton`, `ResultSection`.

## Нужно от бэкенда (вне этого плана)

- Приём и разбор PDF, DOCX и XLSX в тот же единый конвейер, что и CSV или текст.
- В списке загрузок: тип файла, число закупок, число готовых и требующих внимания (частично уже есть в сводке загрузки).
- Хранить ли сам файл для повторного скачивания — решение за командой. Интерфейс закладывает кнопку «Скачать исходный файл», которая появится, только если API отдаёт ссылку.

## Открытые вопросы
